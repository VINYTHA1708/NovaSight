# NovaSight — Unknown-Defect Steel Inspector

## Problem Statement
PS 2.3 — Unknown-Defect Steel Inspector
Track: Smart Manufacturing & Computer Vision

## Objective
Classify known steel surface defects, flag unfamiliar defects, and explore learning a new defect category from five labeled examples.

## Planned Technology Stack
- Python 3.12
- PyTorch
- ResNet-18
- scikit-learn
- Gradio

## Dataset
Planned dataset: NEU-CLS steel surface defect classification dataset.
Dataset source, license, and attribution will be verified before use.

## Project Structure
- src/: application and model code
- data/: dataset files (excluded from Git)
- models/: generated model weights (excluded from Git)
- tests/: tests
- docs/: project documentation
